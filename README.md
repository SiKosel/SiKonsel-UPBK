# SiKonsel UPBK Unindra — Prototype Demo

1. Buat repository publik bernama `sikonsel-upbk` di GitHub.
2. Unggah `index.html`, `style.css`, dan `script.js` ke folder utama repository.
3. Buka Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/(root)`, lalu klik Save.
6. Tunggu sampai GitHub Pages menampilkan alamat website.

Batasan: ini hanya simulasi sisi browser. Tidak ada autentikasi sungguhan, database, atau penyimpanan permanen. Jangan masukkan data konseling nyata.
